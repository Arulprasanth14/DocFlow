## Document visibility per role (confirmed, unchanged)

From `app/services/document_service.py` (`can_read`), in order:

| Role | Can read |
|---|---|
| any | their own documents (`submitted_by == user.id`) |
| admin, hr | every document in the organization |
| worker, trainee | while a run is live: only if they take part in it |
| worker | otherwise: documents in one of their departments; a document with no department is **not** readable |
| trainee | otherwise: **own documents only** - there is no trainee branch, so the departmental fallback never applies |
| superadmin | not special-cased here: with no org role, only their own |

So **`documents:read` does not imply organization-wide read**. A trainee
holds the code and still sees only their own documents; that is
deliberate and confirmed by the product owner.
